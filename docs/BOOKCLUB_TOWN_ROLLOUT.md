# Путеводитель и отдельные темы «Города»

Репозиторий `delta-dashed/DeShuffle`, ветка `codex/town-guide`. Основа — исправления PR #15, включая `f5509f3`. Новый код ещё не развёрнут из локальной среды. Итоговый SHA и результаты тестов указаны в сообщении о завершении.

## Поведение

Вместо длинного каталога в одной теме — закреплённый путеводитель и три отдельные темы: «Текущая книга», «План чтения», «Архив прочитанного». [Discord разрешает одну закреплённую тему в форуме](https://support.discord.com/hc/en-us/articles/6208479917079-Forum-Channels-FAQ); разделы открываются кнопками путеводителя. Сами темы книг и эссе сохраняются.

Существующий `catalog:<guild>` становится путеводителем с прежними ID, страницами-переходами и действиями добавления/порядка/восстановления. Создаются только `catalog:<guild>:current`, `:plan`, `:archive`. Разделы используют существующий тег «Каталог». Ручные названия и права Discord не перезаписываются. Если занят единственный pin, чужая тема остаётся закреплённой, новые разделы публикуются, предупреждение доступно в `/club diagnose` и журнале.

План показывает N встреч по книге + обсуждение эссе, реальные предстоящие/идущие встречи, публичные границы чтения, ближайшие синки, всю очередь и отдельно предложения. Приватные планы ведущих не читаются. Архив содержит только прочитанные книги и количество опубликованных эссе. Даты из старого поля книги не подставляются вместо события обсуждения. Статусы книг, встречи, порядок, автостатусы и исходные эссе этот переход не изменяет.

Отправка идёт через прежний журнал восстановления потерянных ответов Discord, последовательно под общим lock. Повтор и перезапуск сохраняют ID. После обычного полного обновления восстанавливаются удалённые разделы и ссылки на них. Редактирование книги сначала обновляет её карточку, затем только изменившиеся разделы; неизменившиеся разделы в этой операции не запрашиваются через REST. Полный периодический refresh проверяет их отдельно.

Схема БД остаётся **13**; новой миграции нет. Если сервер ещё до PR #15, при обновлении применяются его миграции и правила развёртывания: [BOOKCLUB_FAST_CONTROLS_ROLLOUT.md](BOOKCLUB_FAST_CONTROLS_ROLLOUT.md).

Проверки: полный прогон **846 тестов прошёл**, включая 20 новых тестов разделов и восстановления. Проверены грамматика Python 3.10 и `git diff --check`. Discord и модель в тестах подменены, SQLite временная. Локальный замер для 13 книг при 100 мс на GET: полный refresh — 2097 мс / 18 GET; изменение названия одной книги — 299 мс / 2 GET. Это имитация транспорта, а не измерение production.
